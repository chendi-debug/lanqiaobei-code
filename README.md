# 蓝桥杯单片机学习代码

本仓库保存蓝桥杯单片机相关的学习代码、历届赛题练习、Keil 工程、驱动模板和仿真工程，主要面向 51 单片机基础训练。内容覆盖 GPIO、LED、数码管、按键、定时器、串口、I²C、DS1302、DS18B20、蜂鸣器等常用外设。

## 目录说明

| 目录 | 内容 |
| --- | --- |
| `模板/` | 外设驱动和工程模板，适合开始新练习时复制使用 |
| `模拟/` | 不同届次、不同题目的完整 Keil/Proteus 练习工程，包含题目 PDF、源码和工程文件 |
| `西风模拟1/` | 早期数码管、按键和 LED 等基础练习工程 |

## 如何打开

1. 使用 Keil μVision 打开对应目录中的 `.uvproj` 或 `.uvprojx` 工程文件。
2. 根据工程配置确认目标芯片、晶振频率和头文件路径。
3. 编译工程；生成的 `.hex` 文件可用于烧录或导入 Proteus 仿真。
4. 优先阅读 `Driver/` 中的外设驱动，再阅读 `User/main.c` 中的主程序和状态机。

## 文件保留规则

仓库保留了源码、工程配置、题目资料和必要资源。Keil 自动生成的 `Objects/`、`Listings/` 编译输出没有上传，以减少重复文件；重新编译即可生成。

## 学习建议

建议从 `模板/` 开始，依次掌握 GPIO/LED、数码管与按键、定时器、串口、I²C 和传感器驱动，再阅读 `模拟/` 中完整赛题工程。不同工程可能存在重复文件或个人调试版本，学习时应以同一工程目录内的 `.uvproj`、`Driver/` 和 `User/` 为一组。
