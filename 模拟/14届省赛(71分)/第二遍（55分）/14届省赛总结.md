# 14届省赛第二遍 开发总结

## 一、平均值计算

每次亮→暗触发采集时，累加数据并计算平均值：

```c
Collect_Count++;

// 温度
if(Temperature > Temperature_Max) Temperature_Max = Temperature;
Temperature_Sum += Temperature;
Temperature_Avg = Temperature_Sum / Collect_Count;

// 湿度
if((unsigned char)Humidity > Humidity_Max)
    Humidity_Max = (unsigned char)Humidity;
Humidity_Sum += (unsigned char)Humidity;
Humidity_Avg = Humidity_Sum / Collect_Count;
```

**长按S9清除时**，将 Sum / Max / Avg / Count 全部清零，下次触发重新累加。

## 二、采集触发流程

```
上电
 └─ 先读一次AD初始化 Last_Light_State，防止虚假触发

主循环每50ms执行 Collect_Proc
 └─ 读AD → 判断当前亮/暗状态
     └─ 上次亮(0) && 当前暗(1) → 发生跳变
         └─ Value_Collect_Flag == 0？（未在3秒锁定中）
             └─ 是 → 采集温湿度、记录时分、更新统计
                     Value_Collect_Flag = 1 → 切换温湿度界面
                     中断计时3秒到 → Flag = 0 → 恢复原界面
```

**核心变量：**

| 变量 | 作用 |
|------|------|
| `Last_Light_State` | 记录上次光照状态，检测跳变边沿 |
| `Value_Collect_Flag` | 控制界面显示 + 3秒锁定标志 |

## 三、常见Bug及修复

### 1. AD_Value 类型错误
- 错误：`unsigned char AD_Value`，存不了小数
- 修复：`float AD_Value`

### 2. Collect_Proc 顺序颠倒
- 错误：先用 AD_Value 判断，再读AD
- 修复：先读AD，再判断状态

### 3. 上电虚假触发
- 原因：上电时 Last_Light_State 默认0（亮），若当前是暗，立刻触发
- 修复：main() 里上电先读一次AD同步真实状态

```c
AD_Value = Ad_Read(0x43) / 51.0;
Last_Light_State = (AD_Value < 1.2) ? 1 : 0;
```

### 4. Collect_Proc 无减速狂读AD
- 原因：每次主循环都执行，Last_Light_State 更新过快
- 修复：加 Collect_Slow_Down，50ms检测一次

### 5. 3秒后未恢复原界面
- 修复：触发时备份 Seg_Disp_Mode_Backup，3秒到后恢复

## 四、数码管界面说明

| 界面 | Seg_Disp_Mode | 格式 |
|------|--------------|------|
| 时间界面 | 0 | HH-MM-SS |
| 回显界面 | 1 | 见下表 |
| 参数界面 | 2 | P 空空空空 XX |

**回显子界面（Echo_Mode）：**

| 子界面 | 格式 |
|--------|------|
| 温度回显(0) | C 空 最大温度 - 平均温度 空 |
| 湿度回显(1) | H 空 最大湿度 - 平均湿度 空 |
| 时间回显(2) | F 触发次数 时时 - 分分 |

**采集触发界面（Value_Collect_Flag==1）：**
```
E 空 空 温度十 温度个 - 湿度十 湿度个
```

## 五、长按S9清除数据

- 条件：回显界面 + 时间回显子界面 + 长按超过2秒后松开
- 清除内容：Collect_Count / Temperature_Max / Temperature_Sum / Temperature_Avg / Humidity_Max / Humidity_Sum / Humidity_Avg / Echo_Hour / Echo_Min

## 六、关键变量一览

```c
float AD_Value;                  // 光照AD值（必须float）
unsigned char Last_Light_State;  // 上次光照状态 0亮1暗
bit Value_Collect_Flag;          // 采集标志/3秒锁定
unsigned char Collect_Slow_Down; // 采集检测减速
unsigned int  S9_Press_Time;     // S9长按计时
unsigned char Seg_Disp_Mode_Backup; // 界面备份
unsigned char Collect_Count;     // 采集次数
unsigned int  Temperature_Sum;   // 温度累加
unsigned int  Temperature_Avg;   // 平均温度
unsigned char Temperature_Max;   // 最高温度
unsigned int  Humidity_Sum;      // 湿度累加
unsigned char Humidity_Avg;      // 平均湿度
unsigned char Humidity_Max;      // 最高湿度
unsigned char Echo_Hour;         // 触发时的时
unsigned char Echo_Min;          // 触发时的分
```
