# 15届省赛第2次 问题总结

## 问题1：长按S13切换继电器

### 错误原因

1. 定时器中断里 `Long_Press` 只在第1500ms那一刻为1，下一毫秒被 `else` 清零，`Key_Proc()` 10ms才执行一次，极大概率错过
2. 在 `Key_Down` 时就判断长按/短按，应该在**松开时**判断
3. 缺少 `Key_Up` 的处理

### 正确逻辑

- 按下：开始计时，清除长按标志
- 定时器：超过1500ms置 `Long_Press=1`
- 松开：短按切换 `DAC_Output_Mode`，长按切换继电器

### 正确代码

```c
// Key_Down
case 13:
    Key_Press = 1;
    Timer_1500ms = 0;
    Long_Press = 0;
break;

// Key_Up
case 13:
    if(Long_Press){ Relay_Flag ^= 1; Relay(Relay_Flag); }
    else DAC_Output_Mode ^= 1;
    Key_Press = 0;
    Long_Press = 0;
break;

// 定时器中断
if(Key_Press == 1)
{
    if(++Timer_1500ms >= 1500)
    {
        Timer_1500ms = 0;
        Long_Press = 1;
        Key_Press = 0;
    }
}
```

## 问题2：温度连续两次变化超过1℃报警

### 错误原因

`Tempera_Old` 是局部变量，每次进函数都重置为0，无法保存上次温度值。

### 正确逻辑

用 `static` 保存前两次采样值，判断连续两次差值都超过1℃触发突变报警。

### 正确代码

```c
void Get_Temp_Proc(void)
{
    static unsigned char Tempera_Old1, Tempera_Old2;
    signed char D1, D2;
    if(Temp_Slow_Down < 100) return;
    Temp_Slow_Down = 0;

    Temperature = rd_temperature();
    D1 = (signed char)(Temperature - Tempera_Old1);
    D2 = (signed char)(Tempera_Old1 - Tempera_Old2);

    if(D1 > 1)  L2_Timer = 2000;           // 上升报警
    if(D1 < -1) L3_Timer = 2000;           // 下降报警
    if(abs(D1) > 1 && abs(D2) > 1) L4_Timer = 3000;  // 突变报警

    Tempera_Old2 = Tempera_Old1;
    Tempera_Old1 = Temperature;
}
```

## 问题3：报警指示灯逻辑

### 需求
- L2：温度上升，亮2秒后熄灭
- L3：温度下降，亮2秒后熄灭
- L4：温度突变，0.2秒间隔闪烁，持续3秒后熄灭

### 全局变量

```c
unsigned int L2_Timer, L3_Timer, L4_Timer;
```

### Led_Proc

```c
void Led_Proc()
{
    if(L2_Timer) ucLed[1] = 1; else ucLed[1] = 0;
    if(L3_Timer) ucLed[2] = 1; else ucLed[2] = 0;
    if(L4_Timer) ucLed[3] = (L4_Timer / 200) % 2;
    else         ucLed[3] = 0;
    Led_Disp(ucLed);
}
```

### 定时器中断倒计时

```c
if(L2_Timer) L2_Timer--;
if(L3_Timer) L3_Timer--;
if(L4_Timer) L4_Timer--;
```

### 关键点

`L4_Timer / 200` 每200ms变化一次，取余2得到0/1交替，实现0.2秒闪烁。
