考点1: 运动状态

设备间隔1秒采集距离数据，基于连续两次采集的距离差值（ΔL）判定运 动状态。 

 ① 静止（L1）：ΔL ＜ 5cm   

② 徘徊（L2）：5cm ≤ ΔL ＜ 10cm 

 ③ 跑动（L3）：ΔL ≥ 10cm  运动状态更新与保持机制：当运动状态发生变化时，该状态将立即更新并 锁定3秒，锁定期间保持正常的距离采集功能，但不判定运动状态变化。 

```c
/*全局变量*/
unsigned char Sport_Mode;
unsigned char Distance;
#define abs(x) (x<0)?-(x):(x)

void Get_Distance_Proc()
{
    float Distance_Old = 0;
    signed char D_Distance = 0;
    
    if(Distance_Slow_Down < 1000)return;
    	Distance_Slow_Down = 0;
    Distance = Ut_Wave_Data();
    D_Distance = Distance - Distance_Old;
    Distance_Old = Distance;
    if(D_Distance < 5)
        Sport_Mode = 1;//静止
    else if(D_Distance >= 5 && D_Distance < 10)
        Sport_Mode = 2;//徘徊
    else if(D_Distance > 10)
        Sport_Mode = 3;//跑动
}
```

考点3：当继电器吸合的时候就只触发一次

继电器控制功能  继电器有吸合和断开两种工作状态，工作逻辑要求如下：  同时触发“接近”、“高温”判定时，控制继电器吸合，否则继电器断开。

```c
/*全局变量*/
bit Hot_Flag;//高温标志
bit Near_Flag;//接近标志
static int Last_State = 0;//必须用static static 变量 “保留上一次的值”。
unsigned int Current_State;//当前状态
/*LED相关*/
void Led_Proc()
{
	Current_State = (Hot_Flag == 1 &&Near_Flag ==1)?1：0
     
     if(Current_State == 1)
        Relay(1);
    else
        Relay(0);  
    if(Current_State == 1 && Last_State == 0)
    {
        Relay_Count = Relay_Count + 1;
    }
    Last_State = Current_State;
}
```
